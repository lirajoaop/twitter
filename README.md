# React Twitter Clone (with Bluesky Elements)

This project is a clone of Twitter, with some UI/UX inspiration from Bluesky, built entirely with React. It focuses on implementing the core functionalities of a modern social media platform, such as a dynamic feed, creating posts, and discovering content.

The application simulates a continuous experience by automatically refreshing the feed every 5 seconds. This project demonstrates best practices in modern React development, including state management with Hooks and building a reusable component library.

## Features

* **Create Posts:** Instantly create and post new "tweets" that appear at the top of the feed.
* **Dynamic Feed:** A real-time feed that automatically updates every 5 seconds to fetch new content.
* **Discovery:** A sidebar component that displays trending topics and recommended profiles to follow.
* **Responsive Design:** A fully responsive interface with navigation optimized for both desktop and mobile views.

## Tech Stack

This project was built using the following technologies:

* **React:** The core library for building the user interface.
* **React Hooks:** Extensive use of `useState` and `useEffect` for managing component state and handling side effects (like the auto-refresh timer).

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You must have Node.js (which includes npm) installed on your machine.

### Installation

1.  **Clone the repository**
    ```sh
    git clone [https://github.com/lirajoaop/twitter.git](https://github.com/lirajoaop/twitter.git)
    ```
2.  **Navigate to the project directory**
    ```sh
    cd twitter
    ```
3.  **Install dependencies**
    ```sh
    npm install
    ```
    *(or `yarn install` if you use Yarn)*

4.  **Run the application**
    ```sh
    npm start
    ```
    *(or `yarn start`)*

This will run the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
